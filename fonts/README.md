# Bundled font assets

## LINE Seed Sans KR

- Files: `line-seed/LINESeedKR-Regular.woff2`, `line-seed/LINESeedKR-Bold.woff2`
- Publisher: LINE Corporation
- Official source: <https://seed.line.me/index_kr.html>
- License: SIL Open Font License 1.1

The two WOFF2 files are redistributed without modification from LINE's official
Korean webfont package. UI Style Lab uses only the regular and bold screen
weights and loads them when `koType=lineSeed` is selected.

The SIL Open Font License text is available at
<https://openfontlicense.org/open-font-license-official-text/>.
